# FastTD3 + SimbaV2 + LoRA

This folder contains the LoRA variant of FastTD3 with SimbaV2 networks. The LoRA path applies adapters to the SimbaV2 encoder/residual-block linear layers while keeping the frozen base weights fixed.

Use `scripts/run_lora_example.sh` for a minimal runnable example. See the repository-level `README.md` for environment setup and reproducibility notes.
